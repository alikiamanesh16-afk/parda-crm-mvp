# راهنمای اجرای دستی پروژه (برای تیم)

## پیش‌نیازها (فقط یک بار)

1. **Node.js** نسخه ۱۸ یا بالاتر → از [nodejs.org](https://nodejs.org) نصب کن (نسخه LTS).
   چک کنی نصبه:
   ```bash
   node -v
   ```

## اجرا (هر بار)

```bash
git clone https://github.com/alikiamanesh16-afk/parda-crm.git
cd parda-crm
npm install
npm run dev
```

بعد توی مرورگر باز کن: **http://localhost:5173**

- `npm install` فقط بار اول لازمه (پوشه `node_modules` می‌سازه).
- `npm run dev` سرور توسعه رو بالا میاره — ترمینال باید باز بمونه؛ بستنش = خاموش شدن سایت.
- برای خروج از سرور: `Ctrl+C`

## نکته مهم: فایل داده

فایل `public/parda_crm.csv` (دیتای غرفه‌داران) **توی گیت نیست** و باید دستی بهت داده بشه.
بعد از clone، این فایل رو از کسی که دیتا رو داره بگیر و بذار توی مسیر `public/` پروژه.
بدون این فایل سایت بالا میاد ولی لیست غرفه‌داران خالیه.

## اسکریپت‌های دیگر

| فرمان | کار |
|---|---|
| `npm run dev` | سرور توسعه (hot reload) |
| `npm run build` | ساخت نسخه‌ی نهایی در پوشه `dist/` |
| `npm run preview` | اجرای نسخه‌ی build شده |

## ویندوز راحت‌تر

پوشه‌ی `start.bat` رو دابل‌کلیک کن — همین `npm run dev` رو اجرا می‌کنه (بعد از `npm install`).

##Troubleshooting

- **`npm install` خطا داد:** اینترنت/پروکسی رو چک کن، پوشه `node_modules` رو پاک کن و دوباره بزن.
- **پورت 5173 اشغاله:** یه ترمینال دیگه سرور روشنه؛ اون رو ببند یا `npm run dev -- --port 3000` بزن.
- **لیست غرفه‌داران خالیه:** فایل `public/parda_crm.csv` رو نذاشتی.
- **پیامک ارسال نمی‌شه:** نیاز به کروم دیباگ با نشست وب‌ربا داره (فقط برای تیمی که SMS کار می‌کنه؛ بقیه بدون این هم همه‌چیز دیگه کار می‌کنه).
